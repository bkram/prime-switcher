# Prime Switcher 1.1.0

Prime Switcher brings application and interface routing together in one macOS app. Save independent routes, choose their channels, and switch connections on or off without losing their settings.

## Changes since 1.0.1

- Route individual applications to a mono output or stereo pair, with live signal meters and saved destinations.
- Run multiple saved interface routes with contiguous mono, stereo, or multichannel mappings.
- Restore saved switch states and reconnect routes when their sources and destinations become available.
- Keep audio running when the window closes; reopen the main window with ⌘0 or the Dock icon.
- Use the Routes menu to refresh discovery or turn off every route.
- Include native About information and a new monochrome app icon.
- Rewrite setup, troubleshooting, development, and release documentation.

## Install

Requires macOS 14.2 or later. Download `PrimeSwitcher.dmg`, open it, and drag **Prime Switcher.app** to **Applications**. The app includes Apple silicon and Intel executables.

Allow Microphone access for interface inputs and System Audio Recording access for application capture. New routes start off: save a route, then enable its switch.

## Distribution and compatibility

The supplied packaging uses ad-hoc signing and does not notarize the app. First-launch acceptance on another Mac remains unverified.

Application routing requires matching tap/output sample rates and 32-bit floating-point PCM streams. It does not convert sample rates. Virtual audio devices such as BlackHole must be installed separately. Bluetooth, AirPlay, HDMI, and unusual multichannel layouts need device-specific verification.

Local lint, debug/release builds, and 22 unit tests passed on 2026-10-21. Unit tests use fake audio runtimes. Simultaneous app playback, physical channel isolation, reconnect/relaunch recovery, and permission denial/recovery still require complete hardware verification on the final candidate. See the [release checklist](../RELEASE_CHECKS.md) for the full verification scope and historical observations.
